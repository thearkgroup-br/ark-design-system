# Card

Bloco com título, texto e um detalhe (ícone, número, selo ou rodapé). Serve para empresas, fases, benefícios e resumos.

- `surface` (padrão) sobre `bg`; `sunken` sobre `surface`; `outline` em fundo de mesma cor; `brand` só para o destaque de uma seção (um por seção).
- Título de até 6 palavras; texto de até 2 linhas no computador.
- Card clicável (`href`/`onClick`) muda a borda no hover e leva para um lugar só.
- Em grade, todos os cards da linha têm o mesmo tipo de conteúdo e alinhamento.
- No celular, empilham em uma coluna.
