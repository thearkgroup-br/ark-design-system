# Comparison

"Antes e depois" lado a lado, com VS no meio. No celular, empilha.

- O mesmo número de itens nos dois lados, um respondendo o outro.
- Frases curtas e concretas. Sem números que a gente não pode provar.
- O lado "depois" usa `brand`; o "antes" fica neutro.

## API

| Prop | Tipo |
| --- | --- |
| `before`, `after` | `{ title, items: string[] }` |
| `data-testid` | `string` |

## data-testid

| Parte | Com `iris-landing-compare` |
| --- | --- |
| Lado antes / depois | `iris-landing-compare-before` / `-after` |
| Itens | `iris-landing-compare-before-item` / `-after-item` |
