# Section

Faixa da página: fundo de ponta a ponta e conteúdo no container de 1160 px, com o mesmo respiro em todos os sites.

- Alterne `bg` e `surface` de uma faixa para a outra.
- `layout`: `stack` (empilha), `split` (duas colunas no computador) e `grid` (cards).
- `dense` é para a faixa de destaques.

## API

| Prop | Tipo |
| --- | --- |
| `id` | âncora (`duvidas`) |
| `tone` | `bg` (padrão) · `surface` |
| `layout` | `stack` (padrão) · `split` · `grid` |
| `dense` | `boolean` |
| `data-testid` | `string` (vai na `section`) |
