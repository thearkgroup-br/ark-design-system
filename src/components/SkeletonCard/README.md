# SkeletonCard

Skeleton pronto de um item: `list`, `establishment`, `service`, `booking` (agendamento) e `card`.

- Mostre 3 a 5 enquanto a lista carrega.
- Troque pelo conteúdo real sem a tela pular (mesma altura).

## API

| Prop | Tipo | Padrão |
| --- | --- | --- |
| `variant` | `'list' \| 'establishment' \| 'service' \| 'booking' \| 'card'` | `'list'` |
| `data-testid` | `string` | |

## data-testid

Vai no card. Ex.: `iris-home-business-skeleton`.
